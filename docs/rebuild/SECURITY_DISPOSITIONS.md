## Acceptance and deployment boundary

Local acceptance: **PASS** `cargo fmt --all -- --check`; **PASS** `cargo clippy --workspace --all-targets -- -D warnings`; **PASS** `cargo test --workspace` with `BLACKBOX_TEST_DATABASE_URL` set to the local throwaway-test database service: **465 passed, 2 ignored, 0 failed** (44 suites). This includes the new ITCH, rate-limit, error-body, import-denial, quota-audit, slow-body/in-flight and anonymous-sweep regressions. Initial new-sweep fixture failures were corrected by using a demo-owned admin key and identical cursor-bound query parameters for the keyed/anonymous comparison; no assertion or production behavior was weakened.

No production request, load test, deploy, cloud-setting change, secret read, or market-data commit is part of this disposition. These changes must not be attributed to the currently deployed image before a later release.
